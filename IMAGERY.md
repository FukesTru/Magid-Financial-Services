# Imagery

Two kinds of artwork carry this site.

## 1. Guilloche engravings — in the repo, shipping

`public/engraving/*.svg`, generated by `scripts/generate-engravings.mjs`.

Guilloche is the interlaced line-work printed on banknotes, share
certificates and bond coupons. It is the one decorative language that belongs
to a financial firm by right rather than by association, and it is real
line-work rather than a picture of some — an epitrochoid, the path traced by a
point on a small circle rolling around a larger one:

```
x = r1·cos(t) + r2·cos(ratio·t + phase)
y = r1·sin(t) + r2·sin(ratio·t + phase)
```

Overlay twenty-odd of those at evenly rotated phase and the moire between them
weaves the rosette. `ratio` sets the petal count; `r2/r1` sets how deep the
weave cuts — past about 0.42 the outer edge stops being a circle and turns
into a rounded polygon, which is why the parameters are curated rather than
random.

| Asset | Where |
| --- | --- |
| `rosette.svg` | Homepage hero, bleeding off the right edge |
| `rosette-fine.svg` | Closing call to action, centred like a seal |
| `band.svg` | Trust bar — the cheque-border relative, tiles seamlessly |
| `motif-<service-slug>.svg` | One per service card, petal count 3→14 |

The whole set is 60 KB gzipped. Each asset strokes itself in `currentColor`
and is painted through a CSS mask (the `engrave` utility), not an `<img>` —
an external SVG in an `<img>` renders in its own isolated document where
`currentColor` resolves to black and no page styling reaches inside it. As a
mask, the strokes become the alpha channel and the colour comes from the
element, so one cached file serves the brass watermark on navy and the ink
watermark on bone.

Regenerate with:

```
node scripts/generate-engravings.mjs
```

### What the prompts deliberately exclude

Every prompt forbids **people, faces and hands**, and **any visible text,
lettering, numbers, logos or signage**.

Both are deliberate, and worth keeping if these are ever regenerated:

- Generated lettering comes out as plausible-looking gibberish. On a tax
  firm's website, gibberish on a document is worse than no document.
- Generated people on an accountant's site read as staff or clients. The firm
  has neither of those to show here, and inventing them misrepresents it.

The palette instruction in every prompt — bone, cream, oatmeal, aged brass,
deep navy shadow, 35mm grain — is what makes seven separate generations read
as one commissioned set rather than seven stock photos.
